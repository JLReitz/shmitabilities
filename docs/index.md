# Documentation

Shmitabilities distributes skills, harness packages, and a Codex plugin. Package behavior can be
shared by Pi and DeepSeek Harness (DSH) through separate client interfaces.

## Topics

- [Based capabilities](based-capabilities.md) defines the optional, opinionated baseline for
  documentation, software, language, testing, skill, and harness development.
- [Dependencies](dependencies.md) lists direct package dependencies and manual install steps.
- [Package contracts](packages.md) defines shared configuration and capability package
  boundaries, with links to package documentation.
- [Shmitty workflows](shmit-flow.md) defines the connected project, planning, research,
  knowledge, and version-control workflows and their external integration points.
- [Knowledge structure](knowledge-structure.md) explains the filesystem tree, graph connections,
  source and tool partitions, and their CLI behavior.
