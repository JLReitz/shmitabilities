# Use knowledge

1. Find the tree root, then read its `index.md` and the indexes on the path to the requested topic.
2. Read from knowledge with [knowledge-cli](./knowledge-cli.md) for the smallest relevant concept set.
3. Distinguish sourced claims from analysis by checking each claim's citation support and the cited Reference bodies.
4. Report knowledge gaps from linked open concepts, [add-knowledge](./add-knowledge.md) to them through research when approval is granted.
5. Use the [sanctioned-execution procedure](./sanctioned-executions.md) when a claim requires reproduced evidence. Treat its runtime artifacts as ephemeral evidence.
