# Work through tasks

## 1. Load the task

Read the ticket and the decision that needs its evidence. Load other related tickets only when their detail is needed.

## 2. Run the experiment

Invoke the `prototype` skill. Build the smallest runnable experiment that can answer the ticket's question.

Treat prototype artifacts as evidence for the idea model. Do not use them as the final implementation.

## 3. Record the evidence

Write the actions and observations in the ticket. Link the experiment artifacts and state what the evidence means for the dependent decision.
