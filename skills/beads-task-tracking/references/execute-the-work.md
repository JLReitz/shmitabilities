# Execute the work

1. Run `bd ready`, inspect the selected item with `bd show <id>`, and claim it with `bd update <id> --claim` before editing.
2. Record methods and observations with `bd note <id> "..."`. Append the resolution to the description under its own heading, ao `bd show` displays it first: the answer, supporting evidence, uncertainty, and links to evidence tasks. Post a resolution to the spike before closing evidence tasks. Use `bd comment <id> "..."` for conversational updates.
3. Add discovered work as a separate child task. Finish the claimed scope before starting it.
4. Close an evidence task after its results are posted to the spike. Close the spike after all of its linked evidence tasks are complete and its answer meets the acceptance criteria.
5. End the session with the claimed item closed or updated with its state, evidence, blocker, and next action.

Use the `based-document-author` skill when writing titles, descriptions, notes, comments, and decisions. Run `bd prime` for the installed command reference.
