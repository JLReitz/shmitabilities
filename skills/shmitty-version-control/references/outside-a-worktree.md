# Outside a worktree

1. Locate the project root and task. Name the working branch with the tracked task ID; when the work is not associated with a tracked task, use a descriptive title.
2. Branch a child task from its parent task branch. Otherwise, branch from the repository HEAD selected for the task.
3. Create the task worktree under `{project-root}/.agents/worktrees/` and enter it before changing task files.
