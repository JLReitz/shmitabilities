# Version control

Complete all task work in a Git worktree. Use `shmitty-project-manager` to identify the project root and `beads-task-tracking` to resolve task IDs and parent tasks when the project tracks the work.

Before entering a task worktree, follow [outside a worktree](references/outside-a-worktree.md). After entering one, follow [within a worktree](references/within-a-worktree.md).
