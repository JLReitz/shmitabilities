# Agent Native setup

1. Use `shmitty-project-manager` to select the agent workspace and project location. Read [workspace layout](references/standard-layout.md) to choose the framework shape.
2. Follow [workspace creation](references/workspace-setup.md) to scaffold and validate the new project. Use `beads-task-tracking` for its project database.
3. Use [client and embedded agent integration](references/client-integration.md) for the selected connection and `based-harness-dev` for client discovery and configuration. After creation, read the generated workspace and app instructions and applicable skills before application work.
